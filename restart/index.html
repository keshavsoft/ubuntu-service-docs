ubuntu-service-restart

Safe, verified systemctl restarting, live status polling, and journalctl log inspection for Ubuntu systemd services.

📦 npm Package ↗ 🐙 GitHub Repository ↗ ← Back to Overview

🎯 Why ubuntu-service-restart Exists

Restarting a service on a Linux VPS should never be a "fire and forget" blind bash command. `ubuntu-service-restart` encapsulates the complete lifecycle of service management: checking whether `systemctl` is present, restarting the unit, polling status to ensure it actually came back up, and fetching journalctl logs if something went wrong.

Verified Post-Restart Health

Instead of assuming `systemctl restart` succeeded, it polls `systemctl is-active` immediately afterward to ensure the service is genuinely healthy.

Automated Daemon-Reload

Supports optional daemon-reload before restarting when unit files or environment parameters have changed on disk.

Clean journalctl Extraction

Safely streams the last N lines of logs (`journalctl -u -n 25 --no-pager`) without opening interactive terminal pagers.

Safe Local Simulation

When run on macOS or Windows during development, it simulates systemctl safely without throwing fatal OS command errors.

🚀 Quick Start

npm install ubuntu-service-restart
import { restartService, getServiceLiveStatus, getServiceLogs } from "ubuntu-service-restart";

// Check live status
const status = getServiceLiveStatus("appointment.keshavsoft.com.service");
console.log(status.activeState); // 'active'

// Safe restart with verified health
const result = restartService("appointment.keshavsoft.com.service");
console.log(result.success); // true

// Retrieve last 50 log lines
const logs = getServiceLogs("appointment.keshavsoft.com.service", 50);
console.log(logs.logs);
