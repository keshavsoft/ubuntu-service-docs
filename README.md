# ubuntu-service-docs

> Interactive documentation and architectural showcase website for the ubuntu-service 3-tier suite.

---

## 🌐 Live Pages

* **Overview:** `index.html` (The Post-Git-Pull Paralysis story, 3-tier architecture, and CLI cheatsheet)
* **Architecture Story:** `story.html` (Detailed breakdown of why decoupling detection from restart was necessary)

---

## 📦 What It Covers

1. **The Friction:** Guessing service names on a production Ubuntu VPS after running `git pull`.
2. **The 3-Tier Suite:**
   - `ubuntu-service-detect` (Pure Read/Query)
   - `ubuntu-service-restart` (Execution/Lifecycle)
   - `ubuntu-service` (The User CLI Orchestrator)
3. **Everyday Commands:** Table of `us`, `us restart`, `us logs`, `us port`, and `us name`.
