ubuntu-service

Context-aware CLI to identify, inspect, restart, and view logs of the single systemd service running in the current directory.

📦 npm Package ↗ 🐙 GitHub Repository ↗ ← Back to Overview

🎯 The Top-Level Orchestrator

`ubuntu-service` provides the user-facing CLI experience (`us`). It combines detection from `ubuntu-service-detect` with the execution engine of `ubuntu-service-restart` into a streamlined developer command.

us (Default)

Inspects the service for the current directory, showing active status, assigned port, user, WorkingDirectory, and ExecStart.

us restart

Detects the exact unit and restarts it with verified post-restart status in a single keystroke.

us logs -n 50

Extracts recent journalctl logs for the current service without needing to recall the unit name.

us port & us name

Script-friendly subcommands that output only the raw port or unit name for bash automations.

🚀 Quick Start

# Stand in your project directory and run:
npx ubuntu-service

# Or use the short alias:
us restart
us logs
us port
