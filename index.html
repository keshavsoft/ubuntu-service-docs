📦 Detection & Reading

ubuntu-service-detect

Pure read-only query module. Scans /etc/systemd/system/, matches process.cwd() against WorkingDirectory, ExecStart, or package name, and safely extracts ports.

CLI Reference

Everyday Commands

Command Short Alias Description
npx ubuntu-service us Inspects the service running in the current directory (Status, Port, ExecStart)
npx ubuntu-service restart us restart Safely restarts only the service mapped to the current folder
npx ubuntu-service logs -n 50 us logs -n 50 Streams the last 50 journalctl lines for this service
npx ubuntu-service port us port Outputs only the assigned internal port number (e.g. 3000)
npx ubuntu-service name us name Outputs only the systemd unit name (e.g. appointment.keshavsoft.com.service)
